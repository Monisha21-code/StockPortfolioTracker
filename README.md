# StockPortfolioTracker
Stock Portfolio Tracker developed using Python 
## About the Project

A Python-based Stock Portfolio Tracker developed as part of my CodeAlpha Python Developer Internship.

## Features

- Predefined stock prices
- Add multiple stocks
- Enter stock quantities
- Calculate individual stock value
- Calculate total investment
- Save portfolio to a TXT file

## Technologies Used

- Python
- Google Colab

## How to Run

Run the Python file in Google Colab or another Python environment.
